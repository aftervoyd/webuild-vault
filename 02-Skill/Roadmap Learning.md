# Roadmap Learning: Website, Figma, & Agentic AI

## Fase 1 — Fondasi (Minggu 1-2)
- [ ] HTML & CSS dasar (pahami struktur halaman web)
- [ ] Bootstrap / Tailwind CSS (biar cepat bikin UI)
- [ ] Obsidian setup + cara pakai AI agent untuk belajar

## Fase 2 — Frontend (Minggu 3-4)
- [ ] JavaScript dasar
- [ ] React.js (atau Next.js untuk SEO — penting buat website desa)
- [ ] Responsive design (website desa harus bagus di HP)

## Fase 3 — Design (Minggu 3-6, paralel)
- [ ] Figma dasar: artboard, component, auto-layout
- [ ] Riset desain website pemerintahan (contoh: website kabupaten yang bagus)
- [ ] Buat 1 mockup website desa di Figma

## Fase 4 — Backend & Deployment (Minggu 5-8)
- [ ] Hosting domain (.desa.id atau .web.id lebih murah)
- [ ] WordPress (alternatif cepat untuk client yang butuh CMS mudah)
- [ ] Atau: Next.js + database sederhana (lebih modern, lebih mahal)
- [ ] Deploy: Vercel / VPS / shared hosting

## Fase 5 — Bisnis (Minggu 6+)
- [ ] Buat portofolio (1-2 demo website)
- [ ] Buat proposal penawaran
- [ ] Kenali target: kades, sekdes, operator desa
- [ ] Follow up: kunjungan langsung atau WhatsApp

---

## Stack Rekomendasi untuk Website Desa

### Opsi A: WordPress (CEPAT MULAI)
- Pro: Mudah di-maintain oleh client, banyak theme desa
- Con: Kurang fleksibel, maintenance keamanan
- Cocok: Client yang butuh update sendiri

### Opsi B: Next.js + CMS (MODERN)
- Pro: Cepat, SEO bagus, tampilan modern
- Con: Butuh skill lebih, maintenance lebih rumit
- Cocok: Client yang mau tampil beda, bayar lebih

### Opsi C: Static Site + Git CMS (MURAH)
- Pro: Hosting gratis (GitHub Pages), maintenance minim
- Con: Kurang dinamis
- Cocok: Desa dengan budget sangat terbatas

---

## Catatan Penting
- Website desa harus **mobile-friendly** — mayoritas akses dari HP
- Konten harus **bahasa Indonesia formal** tapi mudah dipahami
- SEO lokal penting: "website desa [nama desa]" harus muncul di Google
