## 🏷️ Identitas

| Item | Isi |
|---|---|
| **Nama** | **Webuild** (= *web* + *build*) |
| **Tagline** | Studio Web Modern |
| **Produk inti** | Website **modern, anti-template, up-to-date** |
| **Segmen** | Desa/pemerintah · UMKM lokal · Umum (bisnis, personal, event) |

**Prinsip produk (anti-monoton):**
- ❌ Bukan theme WordPress generik
- ✅ Stack modern: **Next.js / Astro + Tailwind**
- ✅ Animasi halus, UX enak, loading cepat, SEO kuat
- ✅ Desain custom — tiap klien beda, nggak kelihatan template
