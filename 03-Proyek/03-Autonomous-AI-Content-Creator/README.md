# 🎬 Proyek 03 — Autonomous AI untuk Content Creator

> **Status:** ⚪ RENCANA · **Divisi:** Produk AI + Kreatif

---

## 💡 Ide

Produk **autonomous AI** buat **content creator** — agent yang bikin & posting konten otomatis, dari ide sampai terbit.

## 🎯 Kandidat fitur (draft)

- 💡 Auto-riset **tren** & ide konten
- ✍️ Auto-bikin skrip/naskah
- 🎨 Auto-bikin aset (gambar, motion graphics, voice-over **Sunda/Jawa**)
- 📅 Auto-jadwal & **auto-posting** (TikTok, IG, Threads)
- 📈 Auto-analisa performa + saran

## 🔌 Fondasi teknis yang dibutuhin

| Bagian | Tool |
|---|---|
| Auto-posting multi-platform | **Postiz** (self-hosted, multi-user) |
| Voice-over Sunda/Jawa | Meta MMS TTS |
| Motion graphics | Remotion / FFmpeg |
