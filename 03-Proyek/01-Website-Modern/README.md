# 🌐 Proyek 01 — Website Modern

> **Status:** 🟢 AKTIF · **Divisi:** Produksi (WebBuilder) + Bisnis (SalesAgent)

---

## 🎯 Ringkasan

Jasa bikin **website modern anti-template** (Next.js/Astro + Tailwind) untuk **desa, UMKM lokal, dan umum**.

**Konsumen pertama:** calon kepala desa (pilkades di desa user) — ditawarin **individual** pakai domain `pamekaran.com`.
**Catatan:** kandidat = konsumen pertama *kebetulan*, bukan tujuan akhir.

---

## 🎁 Penawaran

| Produk | Isi |
|---|---|
| **Demo/Portofolio** | Website desa modern (`pamekaran.com`) |
| **Paket Desa** | Profil, berita, **transparansi APBDes**, statistik, katalog UMKM, surat online |
| **Paket UMKM** | Landing page, katalog produk, brand |
| **Paket Umum** | Bisnis, personal, event |

**Posisi jualan:** *"demo Desa Digital"* (produk/visi), **bukan** situs kampanye.

---

## ⚠️ Aturan penting (dari Fase 0)

- Situs desa **resmi** wajib `.desa.id` → pendaftar = **Diskominfo kabupaten** (bukan vendor)
- Situs resmi wajib di **server dalam negeri / PDN**
- **Harga realistis: Rp2,8–5 jt/desa**, maintenance Rp300–700rb/bln
- Hook terkuat: **UU Keterbukaan Informasi** → desa wajib publikasi APBDes
- Wajib patuh **UU PDP** kalau ada data warga
